## 👩‍💻 About Me

I am a **Senior Frontend Engineer** with **10+ years** of experience building scalable, accessible, and high-performance web applications. My core expertise is in the Angular ecosystem — from large-scale Micro-Frontend architectures and NgRx state management to RxJS reactive patterns and GraphQL integrations.

More recently I have been deep-diving into **Agentic AI** — building intelligent pipelines with LangChain, Model Context Protocol (MCP), and LLM evaluation frameworks, and integrating them into Angular frontends backed by Azure AI Foundry.

- 🏗️ Architecting **Micro-Frontend** systems with **Nx Monorepo** and Module Federation  
- 🤖 Designing **AI-powered** full-stack features with LangChain, OpenAI, and Azure AI  
- 📖 Writing in-depth technical articles on Angular, AI, and software design on [Medium](https://medium.com/@piyalidas.it)  
- 🌱 Currently exploring: **Agentic AI**, **LLM Evaluation**, **RAG pipelines**, and **Azure AI Foundry**  
- 💬 Ask me about: Angular architecture, RxJS, NgRx, MFE, TypeScript, and GenAI integrations
